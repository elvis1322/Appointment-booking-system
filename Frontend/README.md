# Frontend — Appointment Booking System

React + Vite + TypeScript klienti për Appointment Booking System.

Dokumentacioni i plotë i instalimit, konfigurimit dhe ekzekutimit ndodhet në **[README i projektit](../../README.md)**.

## Komanda të shpejta

```powershell
npm install
npm run dev      # http://localhost:5173
npm run build
npm run lint
```

API backend duhet të jetë duke u ekzekutuar në `http://localhost:5213`.
